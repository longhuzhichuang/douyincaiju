# Google Sheets 配置模板

## 工作表结构

本项目需要在Google Sheets中创建4个工作表（Sheet）：

---

## 1. 运行配置

用于存储系统的16个运行参数。

### 表头（第1行）
| 参数名 | 参数值 | 说明 |

### 数据示例（第2-17行）

| 参数名 | 参数值 | 说明 |
|--------|--------|------|
| mode | incremental | 采集模式：incremental/full |
| videosPerAccount | 20 | 每账号采集视频数 |
| minLikeCount_incremental | 100 | 增量模式最低点赞数 |
| minLikeCount_full | 1000 | 全量模式最低点赞数 |
| minPlayCount_incremental | 1000 | 增量模式最低播放量 |
| minPlayCount_full | 10000 | 全量模式最低播放量 |
| minInteractionRate_incremental | 0.5 | 增量模式最低互动率(%) |
| minInteractionRate_full | 2 | 全量模式最低互动率(%) |
| minDuration | 10 | 最短视频时长(秒) |
| maxDuration | 600 | 最长视频时长(秒) |
| daysToCrawl | 7 | 增量模式采集天数 |
| enableDedup | TRUE | 是否启用去重 |
| dedupDays | 30 | 去重对比历史天数 |
| similarityThreshold | 0.8 | 内容相似度阈值(0-1) |
| accountDelay | 3 | 账号间延迟(秒) |
| batchDelay | 10 | 批次间延迟(秒) |
| maxRetries | 3 | 最大重试次数 |

### 配置说明

#### 采集模式
- **incremental（增量）**：每天定时采集最近7天的新视频
- **full（全量）**：手动触发，采集账号所有历史视频

#### 质量阈值
- 增量模式：较低阈值，捕获更多潜力视频
- 全量模式：较高阈值，只保留高质量视频

#### 延迟设置
- **accountDelay**：每个账号之间的延迟，避免API限流
- **batchDelay**：每10个账号（一批）之间的延迟

## 2. 监控账号列表

存储待监控的抖音账号信息。

### 表头（第1行）
| 序号 | 账号昵称 | sec_uid | 分类 | 启用状态 |

### 数据示例（第2行开始）

| 序号 | 账号昵称 | sec_uid | 分类 | 启用状态 |
|------|---------|---------|------|---------|
| 1 | 小罐茶官方 | MS4wLjABAAAA1a2b3c4d5e6f7g8h9i0j | VIP账号 | TRUE |
| 2 | 茶频道 | MS4wLjABAAAA9i8h7g6f5e4d3c2b1a0z | KOL | TRUE |
| 3 | 茶道生活 | MS4wLjABAAAAz0y9x8w7v6u5t4s3r2q1p | 内容号 | FALSE |
| ... | ... | ... | ... | ... |

### 字段说明

- **序号**：账号序号（1-100）
- **账号昵称**：抖音显示的昵称
- **sec_uid**：抖音账号唯一标识符（必填）
  - 获取方式：访问账号主页，URL中的 `user/MS4w...` 部分
  - 格式：通常以 `MS4wLjABAAAA` 开头
- **分类**：自定义分类标签（VIP账号/KOL/内容号/品牌号等）
- **启用状态**：
  - TRUE：采集该账号
  - FALSE：跳过该账号

### 使用建议

- 初始配置10-20个账号测试
- 验证无误后扩展到100个账号
- 定期更新sec_uid（账号可能变更）

---

## 3. 采集进度

记录每个账号的采集状态，用于断点续传和失败重试。

### 表头（第1行）
| 账号昵称 | sec_uid | 采集状态 | 已采集视频数 | 最后采集时间 | 批次标识 | 失败次数 | 错误信息 |

### 数据示例（第2行开始）

| 账号昵称 | sec_uid | 采集状态 | 已采集视频数 | 最后采集时间 | 批次标识 | 失败次数 | 错误信息 |
|---------|---------|---------|------------|------------|---------|---------|---------|
| 小罐茶官方 | MS4w... | 已完成 | 850 | 2025-10-23 14:30:00 | 2025-10-23-full | 0 | |
| 茶频道 | MS4w... | 失败 | 0 | 2025-10-23 10:15:00 | 2025-10-23-full | 2 | API超时 |
| 茶道生活 | MS4w... | 未开始 | 0 | | | 0 | |

### 字段说明

- **采集状态**：
  - `未开始`：首次采集
  - `进行中`：正在采集或上次异常中断
  - `已完成`：成功完成
  - `失败`：失败次数≥3次

- **批次标识**：格式为 `YYYY-MM-DD-mode`
  - 示例：`2025-10-23-incremental`

- **失败次数**：0-3，达到3次后放弃重试

### 工作原理

1. 工作流开始时读取此表
2. 根据状态决定是否处理该账号
3. 每个账号采集完成后实时更新
4. 支持断点续传：中断后继续未完成的账号

### 字段说明

#### 基础信息
- **视频ID**：抖音视频唯一标识

- **相关度评分**：0-100分，内容与茶行业的相关度

- **采集时间**：数据采集的时间戳
- **批次标识**：对应的批次ID

## 🔧 设置步骤

### 1. 创建Google Sheets文档

1. 访问 [Google Sheets](https://sheets.google.com)
2. 创建新的电子表格
3. 命名为"抖音视频采集系统"

### 2. 创建工作表

创建4个Sheet（工作表）：
1. `运行配置`
2. `监控账号列表`
3. `采集进度`
4. `视频数据`

### 3. 填充数据

按照上述模板填充：
- **运行配置**：复制16行参数
- **监控账号列表**：添加至少5个测试账号
- **采集进度**：保留表头，数据由系统自动填充
- **视频数据**：保留表头，数据由系统自动填充

### 4. 设置权限

1. 点击右上角"共享"按钮
2. 添加n8n使用的Google账号
3. 权限设置为"编辑者"

### 5. 复制表格URL

复制浏览器地址栏的完整URL，格式如：
```
https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit
```

将此URL配置到n8n的Google Sheets节点中。

---

## 📝 注意事项

1. **不要修改表头**：工作流依赖固定的列名
2. **保持数据格式**：
   - 布尔值使用 `TRUE/FALSE`（大写）
   - 数字不要加单位
   - 日期格式：`YYYY-MM-DD HH:MM:SS`
3. **定期备份**：建议每周备份一次数据
4. **清理旧数据**：视频数据表可以定期归档历史数据

---

## 🚀 快速测试

配置完成后，建议按以下步骤测试：

1. **配置测试**
   - 在"运行配置"中设置 `mode=incremental`
   - 在"监控账号列表"中只启用3-5个账号

2. **首次运行**
   - n8n中手动触发工作流
   - 观察"采集进度"表的更新
   - 检查"视频数据"表是否有数据写入

3. **验证断点续传**
   - 第一次运行到一半时手动停止
   - 查看"采集进度"表的状态
   - 再次运行，验证是否从断点继续

4. **切换全量模式**
   - 修改"运行配置"中的 `mode=full`
   - 手动触发工作流
   - 验证采集到更多历史视频
